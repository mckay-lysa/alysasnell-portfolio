Design System

Every color, font, and shape the site is built from. This page is the picture; src/styles/theme.css is the code. Change one, change the other — always in the same pull request.

Earthy, muted, and quiet on purpose. Cream and beige paper, a soft sage band, walnut brown, and a deep espresso band the page drops into for emphasis. Nothing is saturated. If any of it should be warmer, cooler, or louder, change it here — that's the whole point of having it in one place. Flip this page to dark mode with the button in the corner to check both palettes.

01 — Foundation

Color

Each swatch is a token. The token name is what the code uses, so "make the buttons darker" means changing --as-accent once, and every button on the site follows.

Surfaces

Four grounds, and every section on the site sits on one of them. They alternate as you scroll — cream, beige, sage, espresso — so the page changes chapter without saying so.

--as-bg-deepThe recessed beige band#EBE3D4 / #131009
--as-bg-sageThe muted sage band#DCDDCF / #232A22
--as-bandThe deep espresso band#3A3227 / #322B21
--as-bg-softRaised surfaces#FDFAF3 / #221E17
--as-cardCard background#FDFAF3 / #221E17
--as-photoPhoto blocks, before the real image lands#E2DBCA / #2B271F

On the espresso band

The dark band flips the ink. It has its own small set of tokens so text stays readable when the ground goes dark — never reuse the normal ink tokens there.

--as-band-inkHeadings and copy on the band#F0E9DB / #EDE6D8
--as-band-ink-dimSecondary copy on the band70% band ink
--as-band-ink-muteLabels and metadata on the band52% band ink
--as-band-highlightThe big numbers on the band#D9B98C / #D9B98C

Text

One ink color at four strengths. Using a single hue keeps the page calm.

--as-inkHeadings and body copy#2C2418 / #EDE6D8
--as-ink-dimSecondary copy, descriptions72% ink
--as-ink-muteCaptions, dates, metadata64% ink
--as-ink-faintDecorative, disabled22% ink

Accent & highlight

Accent is a muted moss green — buttons, links, and the italic half of every headline. Highlight is walnut brown, the second voice, reserved for the year markers in the story and the numbers that make her case. Two accents is the limit; a third starts to look like a carnival.

--as-accentPrimary buttons, links#5A6A4E / #A3B492
--as-accent-deepHover and pressed states#46543C / #BCCBAB
--as-accent-softTinted backgrounds, chips10% accent
--as-highlightStat numbers, emphasis#85623D / #C9A177

Contrast matters. Text has to stay readable against its background — that's an accessibility requirement, not a preference. If you pick a new accent color, check it at webaim.org/resources/contrastchecker: body text needs a ratio of at least 4.5:1, large headings at least 3:1.

02 — Foundation

Typography

Two typefaces, bundled with the site so nothing is loaded from Google. Fraunces (a warm serif) for headings, Inter for everything else. The pairing reads as considered rather than corporate.

Set in --font-display and --font-sans in theme.css. If these two fonts don't render on this page, install them or just read the sizes — the site itself bundles them properly.

When you change a color in theme.css, change it in both palettes — light and dark. A token defined only in light mode silently keeps the old value in dark mode, and nobody notices until someone with dark mode on visits the site.
